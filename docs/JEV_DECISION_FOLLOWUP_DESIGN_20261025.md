# 추가 실험 설계 — 결과 확률과 정답 경로 효율

최신 사용자 요청: Microsoft Decision-1의 원리를 조사해 추가 실험을 설계한다. 추론API는 사용하지 않는다. 이미 실행한 마지막 GRPO48 프로토콜은 변경하지 않는다. 아래는 설계이며 새학습/수집을시작한것이아니다. 현재실험이끝난뒤 그결과로 우선순위만정하고, 무작정여러변형을추가하지않는다.

| 순서 | 가설 | 바꿀 것 | 관측할 성공 신호 |
|---|---|---|---|
| 1 | 좋은 행동선택에는 선택확률보다 행동 후 최종정답 가능성과 남은비용 예측이 필요하다 | 공유표현에 행동별EM성공/비용readout을학습하고, 신뢰할수있는경우에만기존행동을대체 | 정답을유지하며공통정답토큰감소, 유용한검색/read변경 |
| 2 | 현재 GRPO는 전부오답인그룹의길이차이까지큰학습신호로만들고있다 | 정확도advantage와정답에조건부인비용advantage를분리, 비용항은그룹표준편차로확대하지않음 | 오답단축만이아닌정답경로단축, EM/F1손실없음 |

## 가설1: 결과를 직접 점수화하는 작은 decision head

단일reader의 기존prefill hidden을공유한다.4행동각각에q=최종EM성공확률과c=남은생성토큰을예측하는작은readout을둔다. 현재value_aux의aux단순추가가아니라 예측값이실제선택에쓰이는지가핵심이다. LLM/도구/인자스키마/생성규칙/문서ID를바꾸지않는다.

학습label은현재고정정책의실제후속실행에서수집한다. 예전bootstrap의후속결과를현재정책의Q라고바꾸어부르지않는다. 고정train192안에서작은질문집합을미리나누어 readout학습과 calibration/신뢰도점검에사용한다. calibration문항의branch결과는readoutfit에사용하지않는다. 과거teacher/base학습노출이있는train집합이므로독립일반화검증이라고주장하지않는다. 최종품질은기존dev64에서정책실행으로판단하고reserved80/final80은보호한다.

행동기준은사전고정된신뢰조건아래 q가reference보다낮지않은후보중c가작은것을고르는방향으로한정한다. 단순점추정의낙관편향으로성공확률이높아보이는후보를무조건고르지않고 calibration이충분하지않으면reference를유지한다. 구체적허용오차/최소개선량은훈련자료로정해dev전동결한다. 근거없이 calibration개선만으로정책성공을선언하지않는다.

최종시험은한candidate대동일reference. 전체F1/EM,공통정답비용,잃은정답/얻은정답비용을함께본다. 순서견고성·대규모head구조탐색은첫긍정신호후로미룬다. 단일suffix의결과는현재정책의조건부표본이지환경불확실성까지잘보정된확률이아니다.

## 가설2: 정확도와 비용의 학습 신호를 분리

현재스모크의rawreward는정답우선이지만 GRPO의그룹정규화는모두틀린그룹의작은비용차도확대한다. 다음설계는이한가설만바꾼다. 표기Q_i=EM_i+0.25F1_i, L_i=EM_i*T_i/(T_i+256):

\[A_i^Q=\frac{Q_i-\bar Q}{\sigma_Q+10^{-6}},\qquad A_i^L=-(L_i-\bar L),\qquad A_i=A_i^Q+0.1A_i^L.\]

모두EM오답인그룹에서는길이항이0이다. 전부같은정답이면정확도항이0이고비용항으로정답경로단축을배운다. 혼합그룹은정확도항과bounded비용항을합친다. 이는어떠한실제정책정확도보장도아니며복합행동의변화는실행평가가필수다. F1부분개선은여전히정확도항에반영한다. 형식항은grammar로상수이면최적화효과를주장하지않고검사만유지한다.

초기화·질문·4rollout·학습률·업데이트횟수·공유reader를현재GRPO와맞추되, 별도고정candidate하나만실행한다. 현재실험의데이터를재사용하면 on-policy초기정책이동일한첫업데이트에한해가능하며출처를명시한다. 추가상호비교계수sweep은하지않는다. 미실행설계이므로성능수치를만들지않는다.

## 진행 기준

현재GRPO결과를먼저완료/저장한다. 두설계는같은문제를다른각도에서보는후보이며동시확장하지않는다. 현재결과가오답단축에집중하면가설2를우선, 판단가치자체가부족하면가설1을우선한다. 어떤경우에도공통정답토큰만감소하고전체정확도가떨어지면성공으로처리하지않는다. 추론API,외부모델정답모방,세계모델,문서선택인터페이스변경은이설계에포함하지않는다.

## 최신 사용자 지표 확정

본실험은 전체평균생성토큰과EM정답평균생성토큰을둘다주요지표로보고한다. 공통정답평균은문항구성변화에의한착시를구분하는보조검증이다. F1/EM유지또는개선없이토큰지표만좋아지는것은성공이아니다. 두평균의tradeoff가생기면하나로숨기지않고모두표시한다. 현재GRPO의사전동결screen과최신사용자요구를구분해기록한다.

인사이트3개: 선택확률≠최종정답확률; 전체절약≠정답효율; 결과예측은실제선택에써야정책으로검증된다. 추가본실험의중심은가설1이며, 가설2는현재GRPO의오답단축이주문제일때선택할대안이다. 두방향을동시에대량실행하지않는다.
