H3는 동결된 reader/base 위에서 미래 답변 품질과 생성비용으로 학습한 종료 보정이다. critic이나 전체 행동 계획 능력을 입증하는 실험은 아니다. 상수 종료 대조군보다 같은 비용에서 더 높은 정확도를 보이는지 검토해야 하며, 상수 대조군의 비용이 일치한다고 가정하지 않는다.

4B base의 과거 탐색적 학습 이력과 새9B base 준비는 동일하지 않다. 모델 세대·크기·구조·토크나이저도 함께 달라져 순수 크기 효과를 주장할 수 없다. 토큰 수는 모델별 단위이므로 모델 내부 비율을 우선 해석한다. 공통 JSON 프로토콜의9B이며 수정 없는 native XML 기준이 아니다. 반복 노출된 개발64 결과이며 독립 검증이나 통제된 지연시간 결과는 아니다. reserved80과 기존 final80은 사용하지 않았다.

## 종합 판단

9B H3는 base 대비 F1 +0.52pp, EM +1/64, 생성토큰 −3.34%로 관측상 작은 동시 개선을 보였다. 그러나 상수 종료 보정 대비 F1 −0.26pp, EM 동일, 토큰 −2.08%여서 상태 기반 정책의 우월성을 입증하지 못했다. 두 정책의 비용도 같지 않으므로 동일 비용 정확도 우위 주장은 불가능하다.

정오가 모두 유지된 정답23문항에서 H3는 오히려81토큰을 더 썼다. 신규 정답2문항에서114토큰, 잃은 정답1문항에서62토큰, 둘 다 오답38문항에서240토큰을 줄여 총335토큰을 절약했다. 따라서 전체 토큰 감소가 정답 문제의 효율 개선을 의미하지 않는다.

4B의 H3는 F1 −0.99pp/토큰 −11.22%, 9B는 +0.52pp/−3.34%였다. 비용 감소 방향은 두 모델에서 관측됐지만 정확도 방향과 절감 규모는 달랐다. 모델 세대·학습 이력·토크나이저 차이가 섞여 있어 큰 모델 때문에 개선됐다는 인과 주장은 하지 않는다.

현재 가능한 주장은 **동결 LLM에 작은 head를 붙여 미래 결과 기반 종료 정책을 학습하고 다른 backbone에서도 실행할 수 있었다**는 것이다. 단순 종료 편향보다 유리한 상태 의존적 다중 행동 정책, 장기 계획 능력, 독립 평가에서의 정확도 개선은 아직 입증되지 않았다. 이번 한정 실험은 완료했으며 추가 GPU 실행은 시작하지 않는다.
