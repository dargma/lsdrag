# 마지막 GRPO 보상 스모크 결과

학습용2문항,4경로씩8수집+greedy전후4회=12회,37.98초,677생성/38064입력토큰. 기능스모크 통과이며 성능검증은 아니다. 전체실험 자동실행 없음.

보상: EM +0.25 F1 −0.10 T/(T+256) +0.02 format_valid. T는 인자+답변의 실제생성전체. 최종JSON은 answer/support_ids, 도구인자는 기존스키마. LLM동결, 작은행동MLP만학습; 생성토큰에 대한직접GRPO가 아니다.

정답문항의토큰은줄지않았고, 같은오답을더짧게생성한변화만관측됐다. 두문항훈련후재실행이므로 일반화/정확도개선 증거가아니다. 두번째그룹은모두같은오답F1이며 길이차이만으로그룹정규화advantage가약±1이된다. 작은비용차도GRPO그룹정규화에서증폭될수있으므로 원보상가중치만으로정확도우선업데이트가보장되지는않는다. 이관측을숨기거나형식보상이학습에기여했다고주장하지않는다.

사용자최신요청대로1회스모크와저장까지만완료했다. 학습경로를바꾸거나보상계수를재탐색하지않았다. 전체학습과개발평가는미실행이며스모크checkpoint를주정책으로승격하지않는다.
