# Qwen3.8 4B distill candidate — 2026-10-23

Decision: acquired and usable for a separate text-only non-thinking integration trial; do not replace the active pilot2 backbone yet. OFF behavior passed three basic generation probes, not a RAG quality benchmark.

Candidate: [empero-ai/Qwen3.8-4B-Distill](https://huggingface.co/empero-ai/Qwen3.8-4B-Distill), community Empero publication, not an official Qwen release. Revision c83cb7aa2999d2f35c43e9ae0634a30eb8985a1e. Its card describes full-parameter SFT on approximately45k internal teacher reasoning traces, based on Qwen3.5-4B; this is publisher-provided provenance, not independently verified training evidence. The card's reported benchmarks use chain-of-thought, so they do not establish quality with thinking disabled.

Pinned public files acquired into /content/local_fast/lsdrag-model-candidates/qwen38-distill/hf. File sizes and SHA256 recorded in lab/registry/qwen38_distill_candidate_20261023/download_verified.json; LFS hashes verified. Weights are not in Git.

Actual smoke used installed Transformers5.18, Qwen3_5ForConditionalGeneration, BF16 CUDA, SDPA, trust_remote_code=False, local_files_only=True, text inputs only. Chat template enable_thinking=False supplies an empty closed think block before generation. Generated outputs: arithmetic `5` (2tokens), valid JSON answer Paris (7tokens), requested keyword_search query in native XML-like tool syntax (28tokens), including end tokens. All three: no generated think tags, no token-cap truncation, no visible reasoning. This does not guarantee all prompts remain non-thinking. Results and exact prompts are in thinking_off_smoke.json and scripts/reporting/smoke_qwen38_thinking_off.py.

Integration work needed: Qwen3.5 hybrid attention/state cache differs from current Qwen3; model norm path is model.language_model.norm rather than model.norm. Existing reader rejects think markers even when empty/closed, so OFF-template support needs an explicit adapter and parity checks. Native tool format differs from existing JSON controller; synchronized parser/schema/prefix tests are required. Hidden size2560 matches numerically but old head weights are not semantically transferable; recapture features and retrain. Standard generation caching worked in the smoke, but custom decision-to-argument KV continuation has not been tested.

Runtime reported reference PyTorch fallbacks for missing flash-linear-attention and causal_conv1d. No active runtime package changes made. Observed shared-GPU smoke times are not comparative performance evidence. Next adoption gates: reader/cache/grammar parity, train-only head retraining, then a separately frozen quality/cost evaluation with thinking OFF throughout. Current Qwen3-4B-Instruct-2507 pilot2 remains unchanged.
