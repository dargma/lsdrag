# PPO 내부 신호: 전역 편향과 상태별 변화

기존train67개동일hidden,24질문,추가LLM실행없음. trunk/normalizer불변검증. Δ(s)=logit_PPO(s)−logit_anchor(s). Softmax공통offset은무의미하므로각합법action쌍의Δa−Δb를분해한다. 질문균등·상태내pair균등가중 least squares로4개전역bias를fit한다. 설명비율=1−잔여제곱합/원래변화제곱합;성능설명비율이아니다. 추가로질문fold밖에서biasfit후heldout신호재구성.

상태별수정의존재/규모는내부신호로진단가능하다. 그것이답변에유용한지는이수치만으로판정불가. 가중일치율과raw상태수분모가다르므로혼동금지. 최종PPO는원train질문으로학습됐으므로OOF도새질문정책일반화증거가아닌bias분해안정성진단. 전체편향이변화를많이설명해도기존anchor자체의상태판단을제거한것은아니다.
